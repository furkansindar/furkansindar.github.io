A Complete Site for a Fictional Eco Hotel

The problem

A hotel site needs several pages that still feel like one site: the same navigation and footer everywhere, without copying that markup onto every page by hand.

The approach

I built the site in HTML and CSS, with a small JavaScript include that injects the shared navigation, banner, and footer on every page, so the shared parts live in one place.

What I built

A complete multi-page site for a fictional eco hotel in San Francisco: a welcome page with a green-hotel pitch, plus pages on museums, green San Francisco, and nearby attractions. The hotel is fictional and the project is coursework, not a client site.
