Madison College coursework, Fall 2024.

A Blog Visitors Can Post To, and an Admin Can Moderate

The problem

A blog needs two sides: a public side where visitors can contribute, and an admin side where someone can review and remove posts.

The approach

I built the public side with PHP and MySQL, styled with Bootstrap, showing posts as cards newest first. The admin side sits behind HTTP Basic Auth and reuses the same posts, with deletion split into two steps so a delete is never accidental.

What I built

Visitors submit a title and a comment, stored in a blog table and shown as Bootstrap cards. The admin page lists the same posts with a delete link on each card; delete goes through a confirmation page first, then a form submission that performs the delete. This is the only Madison PHP project in the set with a real user interface, unlike the API-only projects. This was coursework, so it is presented as a learning project, not as production-ready code.
