Student REST API + Guzzle Client

PHPMySQLREST APIGuzzle

Madison College coursework, Fall 2025.

Build the API, Then Use It

The problem

Student records needed a service that other programs could use, and the course wanted to teach both sides of that service: building an API and consuming one.

The approach

I built the service in PHP with PDO prepared statements against a MySQL student table, returning JSON. Then I wrote a separate client in PHP using Guzzle, the HTTP client library, to call that service.

What I built

The service supports POST to create a student, GET to read one student or all students as JSON, PUT to update, and DELETE to remove. The client runs through the whole cycle end to end: list students, fetch one by id, create a student, delete that student, create another, then update it. The client points at a local server address, as expected for coursework. Unlike the task API, this service has no login step. This was coursework, so it is presented as a learning project, not as production-ready code.
